# Security policy

## Supported versions

Only the [latest release](https://github.com/WorlockM/datetime-stepper-card/releases/latest) receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through [GitHub's private vulnerability reporting](https://github.com/WorlockM/datetime-stepper-card/security/advisories/new). Describe the problem, the steps to reproduce it, and the version of the card and Home Assistant you use.

This is a hobby project, so there is no guaranteed response time. I aim to reply within a week and will let you know when a fix is released.
